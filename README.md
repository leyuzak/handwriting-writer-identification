# Handwriting Writer Identification Using Deep Learning

## Project Overview
This project focuses on identifying the writer of handwritten text using Convolutional Neural Networks (CNN).

The IAM Handwriting Database is used to train and evaluate a deep learning model for writer identification.

## Technologies
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Objectives
- Preprocess handwritten text images.
- Develop a CNN-based writer classification model.
- Evaluate model performance using Accuracy, Precision, Recall, F1-score and Confusion Matrix.
- Analyze the effect of increasing the number of writers on classification performance.

## Dataset
IAM Handwriting Database
